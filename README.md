# Whisper releases

Installers for **Whisper**, Omadli's push-to-talk dictation app. Hold the shortcut, speak, let go, and the text is typed wherever your cursor is.

This repository only hosts the release files. The source code is private. Installed apps also check here for updates.

## Download

| Computer | Download |
|---|---|
| Windows 10/11 (64-bit) | [Latest release](../../releases/latest): `Whisper-Setup-<version>.exe` |
| Mac with Apple Silicon (M1–M4) | [Whisper 0.2.0 for macOS](../../releases/tag/v0.2.0): `Whisper-0.2.0-arm64.dmg` |

The Mac build is released separately and can be a version behind Windows. Use the Mac link above, not the latest release.

Intel Macs aren't supported.

## Install

**Windows.** Run the installer. The build is unsigned, so Windows SmartScreen may warn you the first time: click **More info → Run anyway**. Whisper starts when the installer finishes and then starts with Windows. Updates download in the background and install when you click **Restart now**.

**macOS.** Open the `.dmg` and drag Whisper into Applications. The build is unsigned, so macOS blocks the first launch: open **System Settings → Privacy & Security** and click **Open Anyway**. Whisper also needs **Microphone** and **Accessibility** permission (System Settings → Privacy & Security). On macOS, updates have to be installed by hand from this page.

You need a Whisper account to sign in. Ask your admin.
